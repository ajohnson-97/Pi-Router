# Pi-Router

Custom-built 2.5Gb ethernet and WIFI 6e router/dns-sinkhole using Raspberry Pi SBCs and a custom ATMEGA328P-PU circuit for a toggle switch controlled password system to display system configuration details on the LCD screens and control two servo motors that lock/unlock the enclosure.<br><br>
