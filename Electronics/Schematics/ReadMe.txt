The schematic and wiring diagram feature an Arduino Uno because I designed the prototype using tinkerCAD and it doesn't have an object for the atmega328p-pu chip that I used in the actual project. You can get away with using any Arduino as it uses the same chip, assuming you can accommodate the space and adjust the mounting holes accordingly. If you want to use the atmega chip directly like I did you'll have to research how to do it yourself for the most part, but basically, it's the same connections as the Arduino. You'll need to consult a pinout diagram to make sure you're connecting wires from the digital output pin numbers and not by counting the hardware pins on the chip. For example the first pin on the chip is the reset pin, not digital output pin 1, consult the diagram and you'll understand what I mean. You'll also want to solder a 16Mhz crystal oscillator to the corresponding pins and connect them to ground through 100pF ceramic capacitors. I also added a 10kohm resistor from the reset pin to VCC as a pullup resistor to reset the chip, you can skip this step if you set the pinMode using the built-in pullup resistor in your code. I also put a 100uF polarized capacitor across 5V and ground to smooth out any electrical noise, it's not necessary but recommended.

The schematics might not be fully accurate, they were generated from tinkercad and I changed up the final design a bit in my project. It's more for reference.
